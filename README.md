# SillyTavern-Termux
SillyTavern Termux 一键安装与版本管理脚本。

在主菜单选择 `2) 安装 / 更新 / 修复` 后，可选择：

- `1) 更新至最新版本`：每次从 SillyTavern 官方 GitHub Releases 查询最新正式版本，支持首次安装和已有安装的更新 / 修复。
- `2) 安装 1.14.0 版本`：安装、修复或切换至固定版本 `1.14.0`。
- `0) 返回主菜单`。

首次启动时若尚未安装 SillyTavern，也会进入版本选择菜单。查询最新版本失败时会提示重试，不会自动切换到其他版本。切换版本时保留用户数据，已有代码修改会保存到 Git stash；从新版本降级前建议另行备份数据，数据格式是否兼容由 SillyTavern 决定。

管理菜单支持启动、查看状态、管理器自动更新，以及切换局域网访问。管理器更新与酒馆版本更新相互独立。

开启局域网访问后，SillyTavern 会使用自带的 `listen` 与白名单模式监听网络，并自动放行 IPv4 私有网段。其他设备可通过 `http://手机局域网IP:8000` 访问。未启用账号或其他认证时，请只在可信网络中使用此模式。
